Multi-Container Orchestration

The platform runs as isolated, interconnected microservices controlled via Docker Compose. This ensures deterministic environment parity between staging, dev, and production.

Core Services Breakdown
  • Frontend: Static React build compiled using Vite and served through an Nginx proxy.
  • Backend: Node.js / Express API endpoint implementing security and storage hooks.
  • Database: PostgreSQL instance persisting schemas for users and photo metadata.
  • DevOps Stack: Prometheus server, Grafana visualization dashboards, and Jenkins orchestrator.

Infrastructure as Code (IaC)

Cloud resources are provisioned declaratively with Terraform, guaranteeing auditability, repeatability, and eliminating manual AWS console configuration.

Terraform Scope & Policies
  • Target Bucket: Provisions a globally unique Amazon S3 bucket dedicated to storing uploaded photo blobs.
  • Public Block Bypass: Bypasses default AWS account-level block-public-access settings to permit targeted sharing.
  • Read-Only S3 Policy: Attaches a JSON S3 Bucket Policy allowing anonymous read actions (`s3:GetObject`) for rendering image tags.
# terraform/main.tf resource "aws_s3_bucket" "snapvault_bucket" { bucket = "snapvault-photos-akank" } resource "aws_s3_bucket_policy" "policy" { bucket = aws_s3_bucket.snapvault_bucket.id policy = jsonencode({ Statement = [{ Effect = "Allow" Principal = "*" Action = "s3:GetObject" Resource = "${aws_s3_bucket.snapvault_bucket.arn}/*" }] }) }

Cloud Storage Lifecycle

Images are uploaded as raw binary buffers to S3, bypassing traditional file-system limits and enabling infinite horizontal scaling.

Object Flow Mechanics
  • Base64 Decoding: Client sends compact base64 strings. Backend breaks it into mime-types and decodes payloads to Node buffers.
  • S3 Commands: Sends `PutObjectCommand` utilizing access credentials dynamically injected into Node process environments.
  • Decoupled Architecture: The image binary is stored in S3; only the lightweight URL and meta details reside in the relational database.

Observability & Monitoring

Reliability is monitored continuously using standard cloud DevOps tooling: Prometheus and Grafana.

Telemetry Framework
  • Custom Histogram: Tracks `http_request_duration_seconds` to capture API latency trends.
  • Dynamic Labels: Segments metric dimensions by route path, HTTP method, and returned status code.
  • Dashboard Visualization: Grafana connects to Prometheus as a datasource, providing visual alerts and request counters.

CI/CD Automation Pipeline

A containerized Jenkins Pipeline handles automated compilation, code validation, and server provisioning.

Docker-in-Docker Pattern
  • Socket Mounting: Shares `/var/run/docker.sock` from the host system into Jenkins.
  • Container Management: Allows the Jenkins worker container to spawn sibling Docker containers for test isolation and production deployment.
  • Immutable Deployments: Every code push builds fresh Docker images, completely eliminating drift issues.
Data-in-Transit Security

Token-based authentication enforces strict authorization boundaries. JWTs encapsulate claims securely signed using an HMAC-SHA256 algorithm.

Header Authorization
IAM & S3 Access Control

No secrets are hardcoded. Cloud credentials (`AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`) are dynamically injected via environment variables on container spin-up.

AWS IAM Policies
Cryptographic Hashing

User credentials are salted and hashed utilizing `bcrypt` (10 salt rounds) before database storage, mitigating potential risk from DB leaks.

Bcrypt Hashing

Conclusion & Scaling Roadmap

The current architecture lays down a baseline for standard microservice design. For an enterprise-scale migration, the following path is proposed:

1. Cloud Scalability

Replace the single-node Docker Compose setup with a managed Kubernetes orchestrator (AWS EKS), adding Horizontal Pod Autoscalers (HPA) triggered by Prometheus CPU/Memory metrics.

2. Content Delivery Network (CDN)

Instead of retrieving images directly from the S3 origin, front the S3 bucket with **AWS CloudFront** edge caching to drastically reduce page load latencies globally.
